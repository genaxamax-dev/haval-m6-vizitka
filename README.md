# Визитка Haval M6 — бесплатный сайт

Один файл `index.html`, без сборки и зависимостей. Открывается в любом браузере, работает на телефоне. Карта и шрифты — системные/бесплатные, ключи и регистрация не нужны.

**Сайт опубликован:** https://genaxamax-dev.github.io/haval-m6-vizitka/
Репозиторий: https://github.com/genaxamax-dev/haval-m6-vizitka (GitHub Pages, ветка `main`, HTTPS).

После изменений в `index.html` — `git add . && git commit -m "update" && git push`: Pages пересоберёт страницу автоматически за ~1 минуту.

## Как опубликовать бесплатно

### Вариант 1. Netlify Drop — самый быстрый, без аккаунта

1. Зайдите на https://app.netlify.com/drop
2. Перетащите папку `vizitka` целиком в окно браузера.
3. Получите адрес вида `https://xxxxxx.netlify.app` — сразу работает.

Минус: без аккаунта сайт живёт ограниченное время. Зарегистрируйтесь (бесплатно), затем «Add new site → Deploy manually» и бросьте ту же папку — адрес можно поменять на понятный в Site settings → Change site name.

### Вариант 2. Cloudflare Pages — постоянный бесплатный хостинг

1. https://dash.cloudflare.com → Workers & Pages → Create → Pages → Upload assets.
2. Название проекта, например `haval-m6-yasnogorsk`, Next → загрузить `index.html` → Deploy.
3. Адрес: `https://haval-m6-yasnogorsk.pages.dev`.

### Вариант 3. GitHub Pages

1. Создайте репозиторий, залейте туда `index.html` (можно через веб-интерфейс: Add file → Upload files).
2. Settings → Pages → Source: `main` / `/root` → Save.
3. Адрес: `https://ВАС.github.io/НАЗВАНИЕ-РЕПО/`.

### Вариант 4. Дома без хостинга

Просто откройте `index.html` двойным кликом. Для рассылки ссылкой можно залить на Telegram-хостинг (например, через бот) или на любой из трёх выше.

## Как привязать свой домен

На Netlify / Cloudflare в настройках домена есть «Add custom domain». Купленный домен (например, `havalm6-yasnogorsk.ru`) прописывается там, SSL-сертификат выдаётся бесплатно. Без домена тоже нормально — ссылкой с `pages.dev` можно пользоваться в объявлениях.

## Проверка после публикации

- Откройте сайт с телефона, не только с компьютера.
- Нажмите кнопки Telegram, MAX и телефон — должны открываться чат, MAX и набор номера.
- Нажмите «копировать» у координат.
- Проверьте, что карта отображается и метка стоит на Ясногорске.

## Обновление

Меняете `index.html` → загружаете заново в тот же Netlify/Cloudflare/GitHub. На GitHub Pages достаточно `git push`.
